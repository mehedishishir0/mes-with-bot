# 🤖 Mess WhatsApp Meal Management Bot

এই বটটি আপনার মেসের WhatsApp গ্রুপে স্বয়ংক্রিয়ভাবে প্রতিদিন পোল (Poll) তৈরি করে মিল সংগ্রহ করে এবং সরাসরি আপনার মেস ম্যানেজমেন্ট ওয়েবসাইটে ডাটাবেজে রেকর্ড আপডেট করে।

---

## 🕒 স্বয়ংক্রিয় শিডিউল ও নিয়ম (Schedule & Rules)

| সময় (বাংলাদেশ সময়) | কার্যক্রম (Action) |
|---|---|
| **রাত ১২:১০ টা (00:10)** | WhatsApp গ্রুপে আজকের **দুপুরের মিলের পোল** (0–6) যাবে। |
| **সকাল ৯:৪৫ টা** | দুপুরের ভোট বন্ধ হওয়ার ১৫ মিনিট আগে সতর্কবার্তা যাবে। |
| **সকাল ১০:০০ টা** | দুপুরের ভোট লক হবে; লক বার্তা ও সদস্যভিত্তিক সারাংশ যাবে। |
| **সকাল ১১:০০ টা** | WhatsApp গ্রুপে আজকের **রাতের মিলের পোল** (0–6) যাবে। |
| **দুপুর ২:৪৫ টা** | রাতের ভোট বন্ধ হওয়ার ১৫ মিনিট আগে সতর্কবার্তা যাবে। |
| **দুপুর ৩:০০ টা** | রাতের ভোট লক হবে; লক বার্তা ও সদস্যভিত্তিক সারাংশ যাবে। |

> **গুরুত্বপূর্ণ নিয়ম:** যে সদস্য পোলে ভোট দিবে না, তার মিল স্বয়ংক্রিয়ভাবে **০ (শূন্য)** থাকবে। লকের পর ভোট দিলে নতুন ভোট গণনা হবে না; সদস্যের নামসহ বট একবার জানাবে। আগাম মিল পরিকল্পনা আর হিসাবের অংশ নয়।

## 🚀 লোকাল মেশিনে রান করার নিয়ম (Local Setup)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
cd mess-bot
npm install
```

### ২. এনভায়রনমেন্ট কনফিগারেশন (`.env`):
`mess-bot` ফোল্ডারের ভেতরে `.env.example` ফাইলটিকে কপি করে `.env` নাম দিন:
```bash
cp .env.example .env
```
ভেতরে নিচের তথ্যগুলো দিন:
```env
# আপনার ওয়েবসাইটের URL (লোকালে টেস্টের জন্য http://localhost:3000 অথবা আপনার লাইভ Vercel URL)
WEBSITE_API_URL=http://localhost:3000

# ওয়েবসাইটের .env তে থাকা BOT_SECRET_KEY
BOT_SECRET_KEY=replace-with-a-long-random-secret

TIMEZONE=Asia/Dhaka
```

### ৩. বট স্টার্ট করুন ও QR স্ক্যান করুন:
```bash
npm start
```
টার্মিনালে একটি **QR Code** ফুটে উঠবে।
* আপনার ফোনের WhatsApp খুলুন।
* **Settings > Linked Devices (লিংক করা ডিভাইস) > Link a Device** এ গিয়ে টার্মিনালের কিউআর কোডটি স্ক্যান করুন।
* স্ক্যান সম্পন্ন হলে বট কানেক্টেড হয়ে যাবে এবং একবার স্ক্যান করলেই `auth_info/` ফোল্ডারে লগইন সেশন সংরক্ষিত থাকবে।

### আবার QR স্ক্যান করতে চাইলে

`pnpm run dev` চলা টার্মিনালে `reset` লিখে Enter চাপুন। বট পুরোনো WhatsApp সেশন মুছে নতুন QR তৈরি করবে। তারপর `http://localhost:4000` খুলে QR স্ক্যান করুন। আজকের পোল ও মেসেজ স্টোর এই কমান্ডে মুছবে না।

## 💬 WhatsApp গ্রুপে ম্যানুয়াল টেস্টিং কমান্ড

প্রতিটি মেসের ম্যানেজার আগে নিজের WhatsApp group-এ bot number-টি add করবেন। তারপর website-এর `/settings` পেজে **Connect code তৈরি করুন** চাপবেন এবং সেই group-এ `!connect CODE` পাঠাবেন। Group ID নিজে থেকে সংরক্ষিত হবে। এরপর **মেম্বারবৃন্দ** পেজে প্রতিটি সদস্যের WhatsApp নম্বর সেভ করে **লিংক কোড তৈরি করুন** চাপুন। কোডটি সংশ্লিষ্ট সদস্যকে ব্যক্তিগতভাবে দিন। তিনি গ্রুপে একবার `!link CODE` পাঠালে বট তাঁর WhatsApp পরিচয় ওয়েবসাইটে যুক্ত করবে। Connect code ১৫ মিনিট ও member link code ২৪ ঘণ্টায় মেয়াদ শেষ হয়। টার্মিনাল থেকে LID বা group ID কপি করতে হবে না।

গ্রুপে বটের নিশ্চিতকরণ মেসেজ আসার পর ওয়েবসাইটে **সংযোগের অবস্থা দেখুন** চাপুন। এখন সদস্যের ভোট তাঁর নামের পাশে জমা হবে। অন্য কেউ সদস্যের কোড ব্যবহার করলে ভুল অ্যাকাউন্ট যুক্ত হতে পারে, তাই কোডটি শুধু সেই সদস্যকে দিন।

বট ও ওয়েবসাইট চালু রেখে `!lunch` বা `!dinner` পাঠান, তারপর পোলের একটি অপশনে ভোট দিন। টার্মিনালে `Vote recorded on website for: ...` দেখালে ওয়েবসাইটের মিল ক্যালেন্ডারে আজকের এন্ট্রি যাচাই করুন। দুপুরের ভোট সকাল ১০টার আগে এবং রাতের ভোট বিকাল ৩টার আগে দিতে হবে।

বট গ্রুপে কানেক্টেড থাকা অবস্থায় যেকোনো সময় টেস্ট করার জন্য গ্রুপে মেসেজ পাঠাতে পারেন:
* `!link CODE` — সদস্যের একবারের কোড দিয়ে WhatsApp অ্যাকাউন্ট যুক্ত করুন।
* `!connect CODE` — Settings-এর code দিয়ে একটি নতুন mess group যুক্ত করুন।
* `!poll-lunch` — সাথে সাথে দুপুরের পোল পাঠিয়ে টেস্ট করুন।
* `!lock-lunch` — দুপুরের পোল লক করে রেজাল্ট দেখুন।
* `!poll-dinner` — সাথে সাথে রাতের পোল পাঠিয়ে টেস্ট করুন।
* `!lock-dinner` — রাতের পোল লক করে রেজাল্ট দেখুন।
* `!summary` — আজকের মোট মিল ও সদস্যদের এন্ট্রির লাইভ সামারি দেখুন।
* `!status` — বটের কানেকশন স্ট্যাটাস দেখুন।

## 🌐 Railway বা Render এ ২৪ ঘণ্টার জন্য ডিপ্লয় করার নিয়ম

যেহেতু এটি একটি আলাদা ও স্বয়ংসম্পূর্ণ Node.js প্রজেক্ট:

### Railway-তে ডিপ্লয়:
1. এই `mess-bot` ফোল্ডারটিকে আলাদা একটি গিট রিপোজিটরিতে রাখুন (অথবা মনোরিপো থেকে `Root Directory: mess-bot` সিলেক্ট করুন)।
2. **Railway.app**-এ গিয়ে **New Project > Deploy from GitHub repo** সিলেক্ট করুন।
3. **Variables** ট্যাবে গিয়ে নিচের ভেরিয়েবলগুলো যুক্ত করুন:
   - `WEBSITE_API_URL`: আপনার লাইভ ভের্সেল লিংক (যেমন: `https://your-mess.vercel.app`)
   - `BOT_SECRET_KEY`: আপনার বট সিক্রেট কী
4. ডিপ্লয় হওয়ার পর Railway এর **Logs** ট্যাবে গেলে একবার QR Code আসবে, ফোন দিয়ে স্ক্যান করে নিলেই ২৪ ঘণ্টা লাইভ চলবে!
